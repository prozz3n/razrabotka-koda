# Разработка кода — лабораторные работы

Учебный проект WPF-приложения **Todo** (C#, .NET 6). Репозиторий содержит
последовательно выполненные лабораторные работы 1–12, каждая — в отдельной папке.

## Состав

| Папка | Тема |
|-------|------|
| `Лабораторная 1` | Каркас решения, окна входа и регистрации |
| `Лабораторная 2` | Валидация ввода, пустое главное окно, навигация |
| `Лабораторная 3` | Модель `User`, репозиторий пользователей, авторизация |
| `Лабораторная 4` | Модель `Task`, репозиторий задач, список задач |
| `Лабораторная 5` | Добавление задач, история, пустое состояние |
| `Лабораторная 6` | Единые стили (`Styles.xaml`) |
| `Лабораторная 7` | Переход на страницы (`Frame` + `Page`) |
| `Лабораторная 8` | Анимации переходов и элементов |
| `Лабораторная 9` | Работа с API (`HttpClient`, токен, офлайн-режим) |
| `Лабораторная 10` | Локальная БД (SQLite), «запомнить вход» |
| `Лабораторная 11` | Архитектура MVVM (ViewModels, команды, навигация) |
| `Лабораторная 12` | Модульные тесты (xUnit) |

## Сборка

```bash
dotnet build "Лабораторная 12/Todo.sln"
```
